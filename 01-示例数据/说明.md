# 示例数据说明

本目录的 `hostvote-sample.db` 是 **`scripts/seed-demo.mjs` 随机生成的演示数据库**，
与任何真实活动数据无关。

| 项目 | 内容 |
|---|---|
| 选手 | 10 位，名称为「选手01…选手10」，**无照片** |
| 密码条 | 64 条（4 条专业评审绑定评审席 1-4 + 60 条大众评审），随机生成 |
| 投票 | 约 90 条随机投票，IP 统一使用 `10.0.0.x` 演示网段 |
| 打分 | 80 格（4 位评审 × 10 位选手 × 两个赛事），随机 72-98 分 |
| 排名 | 已由系统按规则算出 |
| 审计日志 / 会话 | 已清空 |

## 直接使用

```bash
# 在代码目录下
HV_DATA_DIR=../01-示例数据 HV_ADMIN_PASS=demo123456 npm start
# 打开 http://127.0.0.1:3000/vote/group
# 后台 http://127.0.0.1:3000/manage  账号 admin / demo123456
```

> 注意：`HV_DATA_DIR` 指向本目录时，程序会把它当作数据目录使用（数据库文件名为 `hostvote.db`）。
> 若不想改动示例库，先把 `hostvote-sample.db` 复制成 `hostvote.db` 再启动。
> 演示环境的密码仅用于本地体验，请勿在任何真实场景沿用。

## 重新生成一份

```bash
node scripts/seed-demo.mjs ./demo-data
```
